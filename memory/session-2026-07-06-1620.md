# סשן 2026-07-06 — שיפוץ עומק של pipeline המילים

## הבעיה שדווחה
מעט שירים עם sync, אי-דטרמיניזם (אותו שיר פעם synced פעם לא), והרבה שירים בלי מילים בכלל.

## שורשי הבעיה (אומתו בבדיקות חיות + לוגים)
1. LRClib נשאל עם כותרת יוטיוב גולמית ("(Official Video)", רווחים כפולים, דו-לשוני) → 0 תוצאות.
2. כשל רשת חולף ב-LRClib נרשם כ"אין מילים" ונכלא בקאש; LRClib איטי (3-15s לשאילתה) ונחנק תחת בורסט.
3. באג `synced`: מילים מ-Genius סומנו כמסונכרנות.
4. מקף צמוד ("ארצי- אף") לא פוצל לשיר/אמן; כותרות מעורבות בלי מקף בכלל לא פורקו.
5. בחירת שיר שגוי כשהשם של האמן הופיע בתוך trackName ("ירושלים של זהב" קיבל את "אנשים טובים").

## מה נעשה (commit 082adf7 בריפו letras)
- `_lrclib_search`: עד ~8 וריאנטי שאילתה (track+artist, שני סדרים, מקטעי מקף, רצפי-שפה בכותרות מעורבות, ניקוי junk words כולל שנים) בגלים מקבילים של 3 עם עצירה מוקדמת.
- `_pick_lrclib_result`: ציון = 2×דמיון-שם-שיר + דמיון-אמן + בונוס duration; סף על שם השיר; gating להתאמה הפוכה; פסילת duration>120s רק ל-synced (plain בלי סינון); העדפת אולפן על Live.
- סדר pipeline: LRClib synced → YouTube captions → plain (lrclib_plain/genius/lyrics.ovh). `synced` נקבע לפי מקור.
- ריפוי קאש: source=none נמחק ונוסה מחדש; plain מנסה שדרוג ל-synced בכל טעינה.
- LRClib: memoization ‏10 דקות, semaphore ‏6, ‏2 ניסיונות timeout ‏12s.
- חיפוש מחזיר מיד (~1.2s) עם `lrc_status=pending`; תגיות נבדקות ברקע ב-`/api/lrc_check` (בפרונט: 3 במקביל לפי סדר כרטיסים, generation guard). סרטונים >15 דק' = none מיידי.
- לוגים: `letras.log` (RotatingFileHandler ‏2MB, ‏gitignored, ‏override ב-`LOG_PATH`) — כל שאילתה/החלטה/timing. זה הכלי לתחקור הבא.
- Dockerfile: ‏`PYTHONUNBUFFERED=1` (פתר את בעיית הלוגים השקטים ב-Railway מהסשן הקודם!) + ‏`gunicorn --threads 12` (חיוני ל-lrc_check מקבילי).
- Genius/lyrics.ovh: מנסים כמה צירופי שיר/אמן (`_song_artist_attempts`).
